# Runic Atelier — Official Studio Website

Static, zero-dependency, bilingual (Korean / English) public hub for **Runic Atelier** (`룬 아뜰리에`), showcasing **AKASHA**, **ARCHE**, and **Pharos**.

- **Live URL:** https://aira1346.github.io/runic-atelier/
- **Contact:** runicatelier@gmail.com
- **Brand Assets:** Uses the official `RunicAtelier_Vector_Kit` SVGs (`Liberation Serif` license notice included in `assets/Liberation-Fonts-Copyright-and-OFL.txt`), AKASHA emblem (`assets/akasha-mark.png`), and ARCHE emblem (`assets/arche-mark.png`).
- **Adding SNS Links:** Edit `STUDIO_CHANNELS` at the top of `app.js` whenever you launch YouTube, X, Reddit, TikTok, or Instagram handles.
